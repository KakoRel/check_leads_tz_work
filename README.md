# Напиши скрипт на одном из языков (Python(желаемо), JavaScript / TypeScript (Node.js), C#, C++, Java) , который:
- Пингует все 4 указанных выше сервиса (используй фиктивные адреса: https://formit.fake, https://leadsync.fake, и т.д.)
- Проверяет ответ (например, 200 OK)
- В случае ошибки — логирует в файл и отправляет уведомление (можно просто имитировать отправку, например, print("Send alert to Telegram"))
- В идеале — сохраняет в лог дату, URL, статус и код ответа
